# Sicherheitsmeldungen / Security reports

Bitte Sicherheitsprobleme vertraulich an **marc.schulz@bbs-einbeck.de** melden. Keine Zugangsdaten oder personenbezogenen Informationen in öffentliche Issues stellen. Normale Fehler und Funktionswünsche können als Issue gemeldet werden.

Report security issues privately to **marc.schulz@bbs-einbeck.de**. Do not post credentials or personal data in public issues. Regular bugs and feature requests may use public issues.
