# macOS · Unterrichtszeit

Quellstand1.0.10, macOS13 oder neuer, Apple Silicon und Intel.

```sh
./build.command
```

Vollständiges Xcode erforderlich. Kalenderprüfungen, Universal-Build, Iconerstellung und lokale Ad-hoc-Signatur erfolgen im Skript. Ergebnis: `build/Unterrichtszeit.app`. Keine Developer-ID-Signatur oder Notarisierung. Bei eigener Installation die konkrete App in den macOS-Sicherheitseinstellungen freigeben, nicht Gatekeeper allgemein deaktivieren.

Der bereitgestellte, vom Autor bestätigte Download ist1.0.8. Quellstand1.0.10 enthält zusätzliche Korrekturen gegen schrumpfende Fenster, weniger unteren Leerraum und die kleine Versionsanzeige. Langzeitverhalten dieser Änderungen noch nicht bestätigt. [Installation / English](../docs/INSTALLATION.en.md).
